# ramGraph

ramGraph is a graph database written in java that loads all the nodes onto RAM to work.

The project loads graph data from CSV files onto RAM and allows for operations to work with and query the graph.


## Features

- Load graph data from CSV files
- RAM based graph representation
- Command-Line Interface using picocli

## Technologies

- Java 
- Gradle
- OpenCSV 
- picocli


## Getting Started

### Requirements

- Java 17+
- Git 

```bash 
git clone https://github.com/DarshanMurugan/ramGraph.git 
cd ramGraph
```
